# Xiaofeng Qiao — Academic Homepage

This repository contains the static source for the academic homepage at:

https://xinqsama.github.io/

## Design direction

This version intentionally follows a conventional academic-personal-site style:

- restrained white / navy palette
- compact navigation
- serif academic headings
- concise research biography
- research interests and research experience before technical tooling
- publications section designed for papers, preprints, code, and BibTeX links
- no framework, build process, analytics, or external font dependency

## Deployment

For the GitHub repository `XINQSAMA/XINQSAMA.github.io`:

1. Upload all files in this folder to the repository root.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Choose `main` and `/ (root)`.
4. The site should become available at `https://xinqsama.github.io/`.

## Publications

The publication section is deliberately conservative. Published/accepted work and public preprints can be listed publicly. Manuscripts still under anonymous review can remain omitted until publication or public-preprint release is appropriate.
