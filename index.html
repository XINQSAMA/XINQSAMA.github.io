Xiaofeng Qiao

Ph.D. Student in Computer Science

George Mason University · Fairfax, Virginia

I am a Ph.D. student in Computer Science at George Mason University. My research focuses on efficient and reliable machine learning, AI/ML systems, and trustworthy LLMs for code and program analysis. I am broadly interested in making modern AI models faster, smaller, and more dependable through model compression, efficient inference, GPU runtime optimization, and validation-guided reasoning for software tasks.

My work spans structured pruning and uncertainty calibration, compiler and GPU optimization, LLM/VLM inference, secure code generation, code translation, and LLM-based decompilation.
