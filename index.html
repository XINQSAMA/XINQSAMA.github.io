I am a Ph.D. student in Computer Science at George Mason University. My research lies at the intersection of AI systems, efficient machine learning, and reliable AI. I am broadly interested in making modern AI models faster, smaller, and more dependable through GPU runtime optimization, compiler and operator optimization, model compression, and efficient inference infrastructure.

My work spans low-level CUDA/PTX execution and TVM-based optimization, as well as pruning, quantization, uncertainty estimation, and serving systems for LLMs and multimodal models.

Research Experience

2024–present George Mason University

GPU Runtime, Compiler, and Operator Optimization

I develop infrastructure for optimizing neural-network computation graphs and GPU kernels across server and edge platforms. The work combines automatic operator search, compilation, code generation, and software-defined GPU scheduling.

  • Built TVM TIR templates for operators including Conv2D, matrix multiplication, attention, and max pooling, with PyTorch bindings.
  • Used surrogate-model-guided search and diversity-aware optimization for single-objective and Pareto-style operator tuning.
  • Implemented ONNX transformations and C++ code generation targeting CUDA and inline PTX.
  • Explored persistent-thread and warp-level scheduling for concurrent inference and fine-grained power management.
  • Selected deployments achieved approximately 60% lower end-to-end latency than TensorFlow XLA and 40% lower latency than TensorRT.
2021–2024 The Pennsylvania State University

Uncertainty-Aware Model Compression

I worked on efficient and reliable deep learning, with a focus on preserving useful uncertainty estimates while compressing models for practical deployment.

  • Combined structured pruning, mixed-precision training, INT8 post-training quantization, and knowledge distillation.
  • Evaluated uncertainty with Monte Carlo dropout and deep ensembles across vision, human-activity recognition, and control tasks.
  • Studied reliability under corruption, out-of-distribution inputs, and adversarial examples.
  • In selected activity-recognition models, compressed roughly 85% of model parameters/size with less than a one-percentage-point accuracy drop.
  • In selected reliability evaluations, uncertainty calibration improved average AUROC by about 12 percentage points after 66% parameter compression.
Selected project AI Inference Systems

Real-Time GPU Inference Infrastructure

I have also worked on production-oriented inference optimization, combining model compression and compiler techniques with serving-side runtime optimizations.

  • Optimized a real-time TTS inference pipeline using graph transformations, operator fusion, loop unrolling, and memory-layout optimization.
  • Used dynamic batching and CUDA streams to improve throughput and GPU utilization.
  • Integrated LLM services with request controls, context management, retrieval, and caching for more efficient and controllable serving.
